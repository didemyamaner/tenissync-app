# tenissync-app

A modern court reservation and player matching dashboard tailored specifically for tennis clubs and community players.

## Core Features
- **Court Schedule Grid:** Interactive timeline (08:00–22:00) supporting Red Clay, Hard, and Grass courts.
- **Booking Engine:** Slot reservations with conflict prevention (Singles/Doubles, optional ball machine).
- **Match Board:** NTRP-based player matching (find hitting partners by skill level and surface preference).
- **Surface & Status Filtering:** Instant calendar filtering.

## Planned Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Lucide React
- **Backend:** Node.js, Express
- **Database:** SQLite (Prisma / better-sqlite3)
- **AI Tooling:** Built with Claude Code CLI
